# 12 — Agent Work Protocol

## Rule

Each agent works only inside its own scope.

The Director coordinates and does not write code.

## Required reading

Every agent must read:

1. `README.md`
2. `23-legacy-isolation-rule.md`
3. `10-director-and-subagents.md`
4. its own READ FIRST file
5. the current sprint file

## Old FinDesk rule

Old FinDesk is only a donor of technical infrastructure.

Old product logic, reports, calculations, tables, screens, and documentation are not truth for v2.0.

## Work report

Each agent report must include:

```text
Subagent:
Scope:
Files read:
Findings:
Changes made:
Risks:
Recommended next action:
Files touched:
```

## Stop rule

If an agent sees a conflict, it stops and reports it to the Director.

## Acceptance rule

No agent may claim success without tests or acceptance criteria.
