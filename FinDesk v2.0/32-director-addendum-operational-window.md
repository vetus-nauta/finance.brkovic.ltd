# 32 — Director Addendum: Operational Input Window

## Rule

The first FinDesk v2.0 screen is the operational input window.

Read before UX or frontend work:

```text
31-operational-input-window-contract.md
```

## Meaning

The first screen is where the user writes income and expenses.

It must show current-month record history and immediate structured verification.

## Not a report

This is not the final monthly report.

This is not analytics.

This is the working operational table.

## Director gate

Do not approve UX work unless:

- writing is fast;
- current history is visible;
- vertical scroll stays inside the records area;
- structured parsed view is reachable to the right or side-by-side;
- current figures are visible near the records;
- reports remain generated later from these records.
