# Sprint 15 - Director Acceptance and Continuation Gate

## Goal

Accept or reject the recovered v2 project state after Sprints 09-14 and define the next sprint number.

## Depends on

- Sprint 14 handoff
- `20-definition-of-done.md`
- `22-sprint-handoff-protocol.md`
- all recovered Sprint 09-14 files

## Director rule

This sprint does not pretend missing implementation is done. It separates accepted documents, completed non-visual gates, skipped visible work, and next work.

## Agents

- Director
- QA/Audit Agent
- Financial Logic Agent as reviewer
- Backend Core Agent as reviewer
- Security/Privacy Agent as reviewer

## Scope

- verify Sprint 09-14 documentation exists;
- compare recovered sprint chain to Definition of Done;
- list skipped visible work;
- list implementation risks;
- name the next sprint;
- preserve v2 as the only project truth.

## Visible-change bypass

No visual work is performed in Sprint 15. All visible changes are explicitly routed to later UX/product execution.

## Forbidden

- no claiming production readiness without tests;
- no mixing routes44 or old branch state into v2 truth;
- no reopening old product logic;
- no silent acceptance of failed gates.

## Exit criteria

- recovered Sprint 09-15 chain is present;
- next sprint is named;
- v2 truth is preserved;
- skipped visible work is documented;
- director recommendation is filed.

## Final handoff

Next sprint should continue from Sprint 16 unless repository evidence shows a stricter unfinished gate.
