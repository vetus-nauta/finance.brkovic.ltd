# Short Report Template

Effective date: 2026-05-26

Use this exact format when a role reports back to the CEO / Project Director chat.

All short reports to the CEO / Project Director chat must be in Russian.

```text
Роль:
Задача:
Статус:
Обновлены файлы:
- <path>
- <path>
Доказательство:
- <short id/group/report/run id or path to FINDINGS section>
Блокер:
Следующий владелец:
```

## Limits

- Maximum: 10 lines plus file paths.
- Do not paste full checklist.
- Do not paste full screenshot list.
- Do not paste long evidence details.
- Do not paste API responses.
- Do not paste reasoning.

If there are screenshots, write only:

```text
Screenshots: listed in FINDINGS.md
```

If there is detailed evidence, write only:

```text
Details: see FINDINGS.md
```
