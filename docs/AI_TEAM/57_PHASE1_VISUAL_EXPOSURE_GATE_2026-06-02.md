# Phase 1 Visual Exposure Gate

Дата: `2026-06-02`
Статус: `обязательный gate перед physical QA`

## Причина

Логика Phase 1 принята, но physical QA нельзя начинать, пока старый интерфейс остается доминирующим первым слоем продукта.

Проблема не в цветах и не в стиле. Проблема в том, что пользователь все еще видит старую структуру приложения:

1. старую композицию экранов;
2. старые навигационные привычки;
3. старые меню;
4. старые пути к действиям;
5. новый смысл, спрятанный за прежней оболочкой.

## Gate Rule

Physical QA открыт только после того, как новая архитектура FinDesk видна в первые минуты использования.

Тестер без объяснений должен понять:

1. что такое FinDesk;
2. как начать;
3. где записывать деньги;
4. где люди;
5. где сдать журналы;
6. где собрать отчет.

## Approved Visible Hierarchy

Первый пользовательский слой должен показывать:

1. `Welcome Hall`
2. `Solo Workspace`
3. `Live Journal`
4. `Team Workspace`
5. `Admin Card`
6. `Employee Card`
7. `Report Assembly`
8. `Reports`
9. `Protected Actions`

## Implementation Direction

Запрещено начинать с:

1. цветов;
2. анимаций;
3. декоративного styling;
4. латок поверх старого меню.

Нужно сначала:

1. убрать старую доминирующую навигацию;
2. вывести Phase 1 hierarchy в первый слой;
3. сделать `Live Journal` главным рабочим экраном;
4. спрятать старые технические разделы в `Protected Actions`;
5. дать прямые переходы к карточке администратора, карточке сотрудника и сборке отчета.

## Alignment Patch

Версия: `20260602-phase1-exposure2`

После локальной проверки обнаружен старый экран `otrStreamGate` с композицией `Выберите отчет` / `Наличные` / `Банковская карта`.

Решение:

1. `stream_gate` больше не сохраняется как рабочее состояние Live Journal;
2. восстановление старого `stream_gate` переводится в `editor`;

4. кнопка смены потока переключает `Наличные` / `Карта` внутри Live Journal;
5. DOM fallback `otrStreamGate` заменен на компактный retired-переход без старой композиции;
6. asset version и service worker подняты до `20260602-phase1-exposure2`.
