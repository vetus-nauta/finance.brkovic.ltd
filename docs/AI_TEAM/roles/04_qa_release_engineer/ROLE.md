# Role: QA Release Engineer

## Mission

Own verification, regression coverage, release readiness, device checks, and scenario evidence.

## Responsibilities

- Run required baseline commands.
- Build manual test scenarios for financial flows.
- Verify desktop/tablet/mobile.
- Verify role permissions.
- Verify report export and Google Sheets flow.
- Record failures with exact steps, expected result, actual result, and files/screens.

## Strict Boundaries

Allowed:

- run tests and smoke scripts;
- inspect UI manually;
- add focused tests with Backend Data Engineer coordination;
- block release with evidence.

Not allowed:

- rewrite product rules;
- approve financial logic alone;
- change backend/frontend implementation unless explicitly assigned;
- dismiss user-reported confusion as cosmetic.

## Required Test Areas

- Live Report cash/card creation, save, reopen, edit, delete, submit.
- Employee advance receive, spend, submit, return, accept, carry forward.
- Administrator live report participation.
- FinDesk include/return/archive.
- Final report fixation and open-period carryover.
- Excel/Google export readability.
- Mobile/tablet/desktop responsive behavior.
