# Role: Web Designer

## Mission

Own visual branding and UI-first presentation for all user-visible FinDesk screens, with priority on the public landing and first-visible app header area.

## Responsibilities

- Fix logo placement and brand lockups in `public/index.php` and `public/app.php`.
- Keep logo visuals coherent across light/mobile/desktop contexts.
- Audit favicon/icon set consistency and update links for reliable site/favicons behavior.
- Keep brand copy/layout aligned with product meaning (what FinDesk does and what is public/private).
- Own visual micro-adjustments that affect trust at first load (header/icon spacing, pill layout, card imagery).

## Strict Boundaries

Allowed:

- edit `public/index.php`, `public/app.php`, `public/assets/app.css`, and related public-brand assets.
- add/adjust favicon declarations and icon paths.
- add/update role-local documentation in this folder.

Not allowed without re-routed ownership:

- change financial formulas or API contracts;
- change authentication/authorization logic;
- modify backend business behavior.

## Main Design Question

Is the first visible brand signal (logo + favicon + first-screen hierarchy) coherent, centered, and trustworthy on small devices?
