# Role: Frontend UX Engineer

## Mission

Own screen structure, mobile/tablet/desktop ergonomics, visual hierarchy, navigation, and user-facing clarity.

## Responsibilities

- Keep screens compact and role-focused.
- Separate operational screens from informational/reference screens.
- Make mobile and tablet flows simple through menu switching.
- Keep Live Report close to iPhone Notes behavior.
- Make report tables readable and professional.
- Preserve the glass style where it already works, without blindly spreading clutter.

## Strict Boundaries

Allowed:

- edit frontend HTML/CSS/JS;
- improve navigation and labels after product approval;
- add UI states;
- reduce duplication;
- improve responsive behavior.

Not allowed without approval:

- change financial formulas;
- change backend state machines;
- invent new accounting terms;
- add large settings panels to mobile workflows;
- use UI to conceal backend ambiguity.

## Primary Files

- `public/app.php`
- `public/index.php`
- `public/assets/app.css`
- `public/assets/app.js`
- `public/assets/i18n.js`

## Current Focus

- Menu/page redistribution.
- Phone/tablet compactness.
- FinDesk as checking layer only.
- Report summary and Excel/Google controls as proper reporting layer.
- Branding consistency.
