# Phase 1 Clean Product Shell

Дата: `2026-06-02`
Статус: `локально внедрено, physical QA открыт только после браузерной проверки`
Asset version: `20260602-phase1-shell2`

## Причина

После visual exposure patch на поверхности все еще были видны старые интерфейсные куски:

1. старые экраны живых отчетов;
2. старые карточки поверх нового меню;
3. старые названия и композиция;
4. смешение нового FinDesk с legacy DOM.

Вывод: новый интерфейс нельзя строить поверх старых экранов.

## Решение

Добавлен отдельный чистый продуктовый слой:

`phase1ProductShell`

Он рендерит основной пользовательский путь без открытия старых модулей:

1. `Старт`
2. `Лично`
3. `Журнал`
4. `Команда`
5. `Администратор`
6. `Сотрудник`
7. `Сборка отчета`
8. `Отчеты`

Старые модули остаются только как legacy/служебные действия через меню `Служебное`.

## Подключенные данные

Новый shell использует существующий backend:

1. `group_list`
2. `group_members`
3. `advance_list`
4. `on_the_go_tape_list`
5. `on_the_go_card_list`
6. `ledger_balance`
7. `on_the_go_list`
8. `on_the_go_signed_sync`
9. `on_the_go_card_submit`

## Важные правила

1. Верхнее Phase 1 меню больше не вызывает старые `ontherun`, `captain`, `reports`.
2. Старые `.ql-module` скрываются в `phase1-clean-mode`.
3. `Журнал` в новом shell сохраняет строки через `on_the_go_signed_sync`.
4. Сдача журнала идет через `on_the_go_card_submit`.
5. Наличные и карта переключаются внутри нового журнала.
6. Новый shell не выбирает первую старую группу автоматически.
7. До явного выбора среды суммы и старые карточки не показываются.
8. Верхнее меню переведено в тонкую строку продукта без старого glass/pill стиля.

## QA Gate

Physical QA пока не закрыт.

Перед допуском нужно руками проверить в браузере и на мобильном:

1. после входа виден новый shell, а не старый экран;
2. кнопки `Старт`, `Лично`, `Журнал`, `Команда`, `Отчеты` не открывают legacy DOM;
3. старые `Быстрые записи`, `Детали`, старые карточки и старые шапки не видны в основном пути;
4. журнал сохраняет строки;
5. журнал сдается администратору;
6. служебное меню все еще дает доступ к legacy-разделам для аварийной работы.
7. старая группа не появляется на старте без явного выбора в поле `Среда`.
