Localhost

Как и где поднят локальный сайт

  • Стартовый скрипт: scripts/start-local.sh
  • Host: 127.0.0.1
  • Port: 18889 через php -S 127.0.0.1:18889 -t public
  • Локальный вход для ручной работы: http://127.0.0.1:18889/reset-local.php
  • Локальный app shell: http://127.0.0.1:18889/app.php
  • Локальный public root: http://127.0.0.1:18889/
  • Локальная API-проверка: http://127.0.0.1:18889/api.php?action=current_user

`reset-local.php` локальный helper: он чистит локальный service worker/cache и переводит в `app.php`. Его не считают production-файлом.

Поведение

Как должен вести себя новый чат

  • Не начинать проект с нуля. Сначала читать handoff, task board, decisions и status-файлы ролей.
  • Не делать reset, checkout, clean и не выбрасывать локальную работу без прямого приказа.
  • Не ломать финансовые формулы, если это не согласовано с Product Finance Architect и Chief Auditor.
  • Не менять backend/API без осознанной Backend/Data ответственности.
  • Полные отчеты ролей хранить в docs/AI_TEAM/roles/*; в главный чат возвращать только короткий рапорт.
  • Любой deploy считать отдельным контуром: backup, preflight, selected files, smoke, deploy report.

Не путать локальный backend candidate в репозитории с тем, что уже реально выложено на production.
