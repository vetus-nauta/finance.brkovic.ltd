# finance.brkovic.ltd Handoff - 2026-05-20

## What This Is

This repository is the cleaned source snapshot for the existing `finance.brkovic.ltd` project.

The live app is a PHP/MySQL PWA called Quick Ledger. It is broader than Captain Fin: it has personal finance, group finance, messages, business/proforma tools, and an On the Go capture flow.

Captain Fin should later be integrated as a separate module, not merged destructively into the ledger code.

## Current Modules

- Auth: email code login, sessions, audit log
- Ledger: income/expense, cash/non-cash, categories, files, reports
- Groups: groups, members, invite links
- Group access: base / manager / advanced on `group_members`
- Messages: group chat and unread state
- Business: company profile, clients, proformas
- On the Go: fast capture, cash/card sessions, later conversion into ledger
- Advances: accountable money issued to employees, submitted from On the Go and accepted into group ledger
- Money UI: group-level issue / submit / accept / return facade for advances
- Premium shell: future premium-account features, currently visible without access gating
- PWA: manifest, icons, install guidance

## Database Warning

The live PHP code uses `on_the_go_tapes` and `on_the_go_sessions`.

The old `deploy/on_the_go_foundation.sql` only creates:

```text
on_the_go_captures
on_the_go_files
```

So the deploy SQL is behind the live database. Before any serious integration, dump the real live schema and reconcile it with `deploy/`.

I added `deploy/on_the_go_sessions_runtime.sql` as a repository marker for the runtime tables expected by current code, but the live DB remains the authority until dumped.

## Integration Strategy With Captain Fin

Captain Fin should become a finance module, roughly:

```text
Finance platform
  - Auth / users / groups / roles
  - Ledger
  - On the Go
  - Business
  - Captain Fin reports module
```

Do not flatten Captain Fin into generic ledger immediately. Keep its report workflow intact:

- current report notebook
- signed `+ / -` entry parsing
- submitted marker
- dimmed submitted cards
- deleted archive
- attachments
- Excel exports
- Google Drive duplication
- local desktop sync

Later mapping can connect Captain Fin report entries into finance ledger entries.
