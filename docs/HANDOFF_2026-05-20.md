# finance.brkovic.ltd Handoff - 2026-05-20

## What This Is

This repository is the cleaned source snapshot for the existing `finance.brkovic.ltd` project.

The live app is a PHP/MySQL PWA now branded **FinDesk**. It is a broader finance platform: personal finance, group finance, messages, business/proforma tools, On the Go capture, accountable-money moderation and the FinDesk middle manager layer.

The previous Captain Fin local report product is now represented by the FinDesk middle layer and should be integrated carefully through that boundary, not flattened destructively into generic ledger code.

## Database Warning

The live PHP code uses `on_the_go_tapes` and `on_the_go_sessions`.

The old `deploy/on_the_go_foundation.sql` only creates:

```text
on_the_go_captures
on_the_go_files
```

So the deploy SQL is behind the live database. Before any serious integration, dump the real live schema and reconcile it with `deploy/`.

I added `deploy/on_the_go_sessions_runtime.sql` as a repository marker for the runtime tables expected by current code, but the live DB remains the authority until dumped.

## Integration Strategy With FinDesk

FinDesk is the middle manager/report layer inside the finance platform:

```text
Finance platform
  - Auth / users / groups / roles
  - Ledger
  - On the Go
  - Business
  - FinDesk manager/report layer
  - Advanced organizer/admin layer
```

Do not flatten the report workflow into generic ledger records immediately. Keep the operational workflow intact:

- current report notebook
- signed `+ / -` entry parsing
- submitted marker
- dimmed submitted cards
- deleted archive
- attachments
- Excel exports
- Google Drive duplication
- local desktop sync

Later mapping can connect FinDesk report entries into finance ledger entries.
